RUANG KERJA YANG BERCERITA

Lebih dari sekadar status.

Aktivitas OpenBot diterjemahkan menjadi ruang yang mudah dipahami—tanpa mengambil alih cara kamu bekerja.

01 / VISUALISASI

Satu kantor, banyak cerita.

Saksikan agent bergerak di antara workstation, lounge, ruang meeting, pantry, dan NOC. Semua digambar sebagai pixel art era 16-bit: tile 16×16, karakter 16×24, 2–10 warna per sprite.

02 / KONTEKS

Tahu apa yang sedang terjadi.

Fase working, ready, blocked, dan idle tampil langsung di ruang kerja dan panel aktivitas.

03 / READ-ONLY

Melihat saja. Tetap di kendalimu.

OVO membaca snapshot SQLite dalam mode read-only. Tak ada chat, instruksi, atau pengiriman task dari dalam kantor.

SEDERHANA & LOKAL

OpenBot bekerja.
OVO memberi perspektif.

OVO berjalan sebagai companion lokal di mesin yang sama dengan OpenBot. Server development membaca database OpenBot dan menyajikan snapshot agent ke visualisasi. Project site ini hanya halaman informasi statis.

SIAP MELIHATNYA?

Mulai dari mesinmu sendiri.

OVO dirancang untuk berjalan berdampingan dengan OpenBot yang terpasang secara lokal. GitHub Pages menyajikan landing page statis ini—bukan runtime viewer.

  • Node.js 20 atau lebih baru
  • OpenBot terpasang di mesin yang sama
  • npm untuk menjalankan Vite
